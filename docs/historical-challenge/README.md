# Historical challenge packet

This directory is the browser-friendly view of the 40-case historical
challenge cohort.

Open the [compact case index](index.json) to see every case, its cohort role,
selection metadata, and the link to its retained case file. Each case file is
small enough to inspect directly in GitHub or through a raw download.

The [complete packet](../historical-challenge-cohort.json) is the canonical
audit artifact. It contains the same full case payloads and independent review
slots in one file. The [review protocol](../historical-challenge-review.md)
defines the blind labelling and adjudication rules.

This cohort is pending independent labels. Do not treat its selection rules or
case files as Page 47 results. The comparator output is intentionally absent
from the review packet until independent labelling is complete.
